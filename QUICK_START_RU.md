## 4. Короткая опора для защиты

- DSU: find находит корень группы; union соединяет две разные группы. Union by size и path compression ускоряют операции.
- Mission 1: получаем дерево — все клетки связаны, циклов нет, поэтому сломано ровно n−1 стен.
- Kruskal: сортируем стены по стоимости и объединяем разные компоненты.
- Prim: растим одно дерево; priority queue даёт самую дешёвую стену к новой клетке.
- DFS: идём в глубину; массив stack хранит текущий путь. При тупике возвращаемся назад.
- SCC: из каждой клетки зоны можно добраться до любой другой и обратно по slides.
- Kosaraju: первый DFS запоминает порядок завершения; второй DFS идёт по обратным рёбрам в обратном порядке завершения.
- Routes: номера зон уже в топологическом порядке. Для ребра u -> v обновляем `distance[v] = min(distance[v], distance[u] + cost)`.
- Flow stages: длиннейшая цепочка по всему графу зон. Это не длина самого дешёвого маршрута.
- Fastest route cost: движение внутри зоны считается бесплатным; между двумя зонами берём самый дешёвый slide.

Для защиты нужно понимать код, а не только эти определения. По условиям защиты AI-инструменты использовать нельзя.
